Tektronix TBS1072B-EDU

Drive the oscilloscope from your browser over WebUSB, and save what it measures.

Not connected
This browser cannot talk to the instrument. The WebUSB API is required, and is available in desktop Chrome and Edge (and Chromium derivatives). Firefox and Safari do not implement it, and neither do browsers on iOS. You can still explore the controls below — nothing will be sent to any hardware.
WebUSB needs a secure page. Open this page over https:// or on localhost.
First time? The scope must be bound to the WinUSB driver before any browser can see it, and its rear port must be set to Utility → Options → USB Device Port → Computer. See docs/SETUP.md.

Waveform

Every point here came off the instrument: 2500 samples per channel, scaled by the preamble captured with them. The graticule matches the scope's own screen — ten divisions across, eight down. 



      

        
        
        
        
        
      

    


    

      

        
Measurements

        

          Taken by the instrument itself over the whole acquisition, not computed
          from the transferred record — so they will differ slightly from the
          statistics under the plot. That difference is real, not a bug.
        

      


      

        
        
        
      


      

    


    


    

      

        
Instrument screen

        

          The oscilloscope's own display, transferred over USB — useful when you
          want the lab report to show what was actually on the bench.
        

      

      

        
        
      

      

    


    

      

        
Command console

        

          Everything exchanged with the instrument. Commands are SCPI over
          USBTMC: CH1:SCALE 5.0E-1 sets channel 1 to 500 mV/div,
          and anything ending in ? is treated as a query.
        

      


      

        
        
        
        
        
        
      


      

    

  


  

    

      The TBS1072B has no USB-serial bridge inside it — it is a native USBTMC
      device — so this page uses the WebUSB API and speaks the
      USBTMC bulk protocol directly. Settings are remembered in this browser
      only; captures are held in memory until you save them.
